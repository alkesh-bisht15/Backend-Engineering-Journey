## Challenges Completed

### Challenge 1 — Func
Created a `Func<int, int>` to calculate the square of a number.

### Challenge 2 — Action
Created an `Action` to perform a simple greeting/message operation.

### Challenge 3 — Predicate
Created a `Predicate<int>` to check whether a number is positive.

### Challenge 4 — LINQ
Practiced LINQ operations including:

- Filtering numbers
- Finding even numbers
- Transforming values
- Finding the first matching element

### Challenge 5 — Delegate vs Lambda
Explained the difference between delegates and lambda
expressions and when each is useful.

### Challenge 6 — Events
Designed an event-based `OrderService` example to understand
how events can be used for communication between components.

## Key Takeaways

- Delegates allow methods to be treated as values.
- `Func`, `Action`, and `Predicate` are commonly used delegate types.
- Lambda expressions provide concise ways to define functions.
- LINQ makes collection processing much cleaner.
- Events allow one component to notify other components when something happens.
- These concepts are heavily used throughout modern C# and .NET.
